**Tarih:** 2026-09-24

**Kapsam:** Tüm repository  
**Odak:** Doğruluk, güvenlik, test kapsamı, performans

## Yönetici Özeti

Kod tabanı iyi ayrılmış servis sınırlarına sahip. TypeScript derlemesi, lint ve birim testleri başarılı. Ancak kritik güvenlik sınırları eksik: webview tarafından gönderilen yollar doğrulanmadan dosya sisteminde kullanılıyor. Prompt akışlarında olay korelasyonu ve iptal yalıtımı bulunmuyor. Test kapsamı belirlenen eşiklerin belirgin biçimde altında.

**Genel risk: Yüksek**

Öncelikli düzeltmeler:

1. Workspace ve skill path containment uygulanmalı.
2. Prompt/session olaylarına correlation ID eklenmeli.
3. Server startup serialize edilmeli.
4. Abort ve timeout kaynak temizliği düzeltilmeli.
5. Mutation hataları UI'a başarı gibi aktarılmamalı.

## P1 — Kritik Bulugular

### P1-01 — Context attachment workspace dışına çıkabiliyor

**Zorluk (1-5):** 3/5

**Dosyalar:** `src/extension/services/ContextService.ts:24-59`, `src/extension/services/SidebarMessageHandler.ts:237-244`

`ContextService`, webview'dan gelen `ContextPart.path` değerini workspace containment kontrolü olmadan `vscode.Uri.joinPath()` ile okuyor. `../` veya mutlak yol, aktif workspace dışındaki dosyalara erişebilir. `openDiff()` aynı sınır kontrolünü kullanmıyor.

Deny pattern listesi workspace sınırı değildir; symlink, mutlak yol ve traversal açıklarını engellemez.

**Etki:** Webview etkisiyle extension host üzerinden keyfi dosya okunabilir ve içerik model isteğine eklenebilir.

**Düzeltme:**

- Workspace köküne göre normalize edilmiş path oluştur.
- Mutlak yol ve `..` traversal değerlerini reddet.
- `path.relative(root, resolvedPath)` ile containment doğrula.
- Mümkünse canonical path/symlink doğrulaması yap.
- Aynı kontrolü `openDiff()` için uygula.
- Traversal, mutlak yol, mixed separator ve symlink testleri ekle.

### P1-02 — Skill name path traversal ile keyfi dosya okuma

**Zorluk (1-5):** 2/5

**Dosya:** `src/extension/services/SkillService.ts:36-45`

`load(name)`, webview tarafından gelen ismi doğrudan skills dizinine bağlıyor:

```ts
path.join(skillsDir, name, 'SKILL.md');
```

Traversal içeren isim `.agents/skills` dizininden çıkabilir.

**Etki:** Başka bir `SKILL.md` veya benzer dosya içeriği modele gönderilebilir.

**Düzeltme:**

- Skill ismini güvenli identifier ile sınırla: `^[A-Za-z0-9._-]+$`.
- Final path'in doğrudan skills dizini altında kaldığını doğrula.
- Path fragment yerine explicit directory lookup kullan.
- Traversal testleri ekle.

### P1-03 — Eşzamanlı server startup süreç sızıntısına yol açabilir

**Zorluk (1-5):** 4/5

**Dosya:** `src/extension/services/ServerProcessManager.ts:49-69,150-226`

`start()` yalnızca `this.server` kontrolü yapıyor; in-flight startup lock yok. `webviewReady()` ve `sendMessage()` eşzamanlı çalışırsa birden fazla child process spawn edilebilir. Sonraki startup state'i ezebilir ve önceki process unreachable hale gelebilir.

**Etki:** Orphan process, yanlış URL/auth state, kapanışta temizlenmeyen kaynaklar.

**Düzeltme:**

- Tek `startPromise` kullan.
- Startup ve shutdown'u serialize et.
- Stale process exit event'lerini process identity ile filtrele.
- Başarısız/obsolete process'leri sonlandır.
- Eşzamanlı startup ve stale-exit testleri ekle.

### P1-04 — Prompt iptali session/request scope taşımıyor

**Zorluk (1-5):** 4/5

**Dosya:** `src/extension/services/OpencodeCli.ts:173-190,226-230,367-374`

Tek global `AbortController` tüm promptlar tarafından paylaşılıyor. Yeni prompt başlatmak önceki promptu, session A abort işlemi ise session B promptunu iptal edebilir.

**Etki:** Yanlış prompt/session iptali ve event dispatcher karışıklığı.

**Düzeltme:**

- Request ID veya session ID bazlı controller kaydı tut.
- Yalnızca hedef request'i iptal et.
- Event'leri request/session ile ilişkilendir.
- Eşzamanlı session testleri ekle.

### P1-05 — Stream eventleri request/session ile ilişkilendirilmiyor

**Zorluk (1-5):** 4/5

**Dosyalar:** `src/extension/services/ChatCoordinator.ts:23-31`, `src/shared/types.ts:491-511`, `src/webview/hooks/useMessageHandler.ts:82-153`

`receiveMessage`, `receiveChunk`, `streamEnd`, `messageMeta` ve `reasoningContent` mesajlarında request/session ID yok. Webview global streaming ref kullanıyor ve chunk'ları son assistant mesajına ekliyor.

**Etkili hata senaryosu:**

1. Prompt A başlar.
2. A iptal edilir.
3. Prompt B başlar.
4. Geç gelen A chunk'ı B'ye eklenir.
5. A `streamEnd` event'i B'yi sonlandırıp busy state'i temizler.

**Düzeltme:**

- Tüm streaming mesajlarına request/session correlation ID ekle.
- Sadece eşleşen assistant mesajını güncelle.
- Busy, reasoning, metadata ve streaming state'i request scope'a taşı.
- Delayed-event regression testleri ekle.

## P2 — Orta Öncelikli Bulugular

### P2-01 — Timeout stream'i sonlandırmıyor

**Zorluk (1-5):** 2/5

**Dosya:** `src/extension/services/OpencodeCli.ts:262-329`

Timeout `finish()` çağırıyor ancak controller abort edilmiyor. HTTP/SSE stream açık kalabilir ve reader, callback ile extension-host kaynakları sızabilir.

**Düzeltme:** Timeout'ta controller'ı abort et, stream/reader kaynaklarını iptal et, cleanup garantisi sağla.

### P2-02 — Mutation hataları başarı gibi gösteriliyor

**Zorluk (1-5):** 3/5

**Dosyalar:** `src/extension/services/SessionService.ts:40-44`, `src/extension/services/SidebarMessageHandler.ts:299-311`, `src/extension/services/ApiClient.ts`

Session delete ve revert/unrevert sonuçları bazı akışlarda kayboluyor. Server reddederse UI başarı gösterilebilir. Aktif session silinse bile `_currentSessionId` temizlenmiyor.

**Düzeltme:** Boolean/typed failure propagate et, aktif session state'ini başarılı silmeden sonra temizle, başarı event'ini yalnızca server başarısından sonra gönder.

### P2-03 — API key kaldırma remote/local state'i desenkronize ediyor

**Zorluk (1-5):** 2/5

**Dosya:** `src/extension/services/AuthService.ts:27-31`

Remote `removeAuth()` başarısız olsa bile local SecretStorage siliniyor.

**Düzeltme:** Local secret'ı yalnızca remote removal doğrulandıktan sonra sil. Partial failure durumunu raporla.

### P2-04 — Root-level secret dosyalar deny pattern'larından kaçabilir

**Zorluk (1-5):** 2/5

**Dosya:** `src/extension/services/readPatterns.ts:1-65`

`**/.env`, `**/package-lock.json` ve benzeri pattern'lar root-level dosyalarda mevcut path eşleştirmesiyle güvenilir çalışmayabilir.

**Düzeltme:** Root ve nested path testleri ekle. Separator normalization ve explicit root pattern desteği kullan.

### P2-05 — Image context sessizce atılıyor

**Zorluk (1-5):** 3/5

**Dosyalar:** `src/shared/types.ts:247-266`, `src/webview/components/BottomInput.tsx:160-174`, `src/extension/services/ContextService.ts:22-29`

UI image attachment üretiyor; `ContextService` non-file item'ları atlıyor. Kullanıcı görsel seçiyor fakat görsel modele gönderilmiyor.

**Düzeltme:** MIME, base64 ve decoded size doğrulaması yap. Server formatına dönüştür ve round-trip testi ekle.

### P2-06 — `/init` UI'yi busy bırakıyor

**Zorluk (1-5):** 1/5

**Dosyalar:** `src/webview/App.tsx:165-185`, `src/extension/services/SidebarMessageHandler.ts:199-215`

`handleSend()` `busy=true` yapıyor; `/init` yalnızca `runCommand` gönderiyor ve `streamEnd` gelmediği için busy state temizlenmiyor.

**Düzeltme:** Streaming üretmeyen komutlar için başarı ve hata yollarında busy state açıkça sonlandır.

### P2-07 — File search yanıtları out-of-order olabilir

**Zorluk (1-5):** 2/5

**Dosyalar:** `src/webview/components/BottomInput.tsx:130-140,258-266`, `src/webview/hooks/useMessageHandler.ts:272-277`

Eski query sonucu yeni query sonucundan sonra gelirse stale sonuçlar güncel aramayı ezebilir.

**Düzeltme:** Query/request ID ekle, obsolete request'leri iptal et veya ignore et.

### P2-08 — Runtime message validator bilinmeyen type'ları kabul ediyor

**Zorluk (1-5):** 2/5

**Dosya:** `src/extension/providers/SidebarProvider.ts:54-72`

`validatePayload()` bilinmeyen type için `true` döndürüyor. Declared discriminated union ile runtime validation uyuşmuyor.

**Düzeltme:** `WEBVIEW_TO_EXTENSION_TYPES` üzerinden type doğrula; bilinmeyen ve malformed mesajları reddet.
